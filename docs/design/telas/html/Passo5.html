Como deve ser a planilha
Siga este exemplo para evitar erros na importação. Os campos com * são obrigatórios.
Nome completo *CPF *TelefonePlano *Vencimento *E-mailRafael Souza123.456.789-00(11) 99999-0000Mensal10/12/2026rafael@email.comJuliana Prado987.654.321-00(11) 98888-0000Trimestral05/12/2026juliana@email.com
Regras
  • ✓A primeira linha é o cabeçalho. Uma linha por aluno.
  • ✓Colunas com * são obrigatórias: nome, CPF, plano e vencimento.
  • ✓Datas no formato dia/mês/ano, por exemplo 10/12/2026.
  • ✓O plano deve ter o mesmo nome cadastrado em Planos.
  • ✓CPF com ou sem pontos. Telefone com DDD.
Erros comuns e como corrigir
10-12-26→10/12/2026
Mensal 2x→Mensal
CPF em branco→Preencha ou apague a linha
(11)9999→(11) 99999-0000
