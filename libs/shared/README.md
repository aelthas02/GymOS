# @gymos/shared

Código compartilhado sem dependência de framework de UI, usado pelo front, pela API e pelo agente da
catraca. Os pacotes previstos nos tickets (dinheiro, validação, eventos, regras de acesso) têm donos
próprios no `CODEOWNERS`.

Tags `scope:shared` e `type:util`: importa só libs `type:util`. Testes: `pnpm nx test shared`.
