cliente HTTP fino (ADR-005). Dono: Agente 4 (T11). Nada aqui é escrito à mão.

Tags `scope:shared` e `type:data-access`: `libs/ui` não importa esta lib. Testes:
`pnpm nx test api-contracts`.
